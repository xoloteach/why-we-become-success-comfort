# Three native portrait Shorts

Original narration reused without speed changes or new voice synthesis. Script is an editorial selection of complete original lines, with documented source ranges, 15 ms boundary fades and an affine timing map rebuilt for the cuts. Existing selected user artwork is recomposed; no portrait sheets or replacement images generated.

1080×1920 / 30 fps. Warm paper, charcoal/rust, Montserrat. Separate headline/hero/semantic diagram/caption lanes. Per short: 3 graphic treatments, receiving-node gated loops, true polyline markers, 2.5-second unstretched canonical ending included in 35–55 seconds. Captions: max 5 words, max 2 lines, stable font, white with active rust.

Run `python shorts/render_shorts.py prepare`, inspect QA states, then `python shorts/render_shorts.py 0` (or 1/2). Shared landscape code is not modified. Private episode repo remains private; no publication audience change.

Source audio DSP was completed before STT. Matched and interpolated timing estimates are retained and disclosed; no millisecond-accuracy guarantee. Real platform UI cannot be verified before an upload; reserved platform lanes are inspected with an explicitly illustrative UI overlay, not misrepresented as an actual posting preview.
