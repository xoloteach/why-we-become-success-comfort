# Independent production preparation

## Visual thesis
Immediate comfort is a soft enclosure; a better future is an open doorway reached through ordinary small actions. Start observational, move through false productivity and immediate rewards, pivot to environment and protective avoidance, finish with self-trust. Do not shame healthy rest or illustrate success as a mansion/luxury stereotype.

## Motion assignments
Use split comparisons for present/later; paths for repeated choices; a node-by-node loop for discomfort → avoidance → relief → guilt → promise → renewed discomfort; a short-work timer only for the script’s ten-minute example; stack completed actions as evidence; switch between protective and enabling environments. All quantities must be script-supported; no fake empirical plots. Actual illustrations remain user-supplied.

## Label / caption contract
Create typography in the renderer, never bake it into images. Keep a separate lower caption lane. Cue each label from verified speech. All draft timestamps are null. Final subtitles follow processed narration; no stretching audio to match artwork.

## Audio preparation specification
Use supplied narration if later uploaded. Preserve script wording. Process vocal cleanup and pause trimming before STT alignment; then never change timing without realignment. No audio has been synthesized or inspected. Provider endpoint and voice must be verified before an actual TTS request.

## Next factual gates
1. Inspect original images for correct grid, canonical character, clean subtitle band, no pseudo-text or repeated crops.
2. Extract real boundaries and prepare masks/layers, then log all used or intentionally omitted panels.
3. Finish narration, align words and scene cues, assign real start/end values.
4. Build and inspect actual captioned frames and motion clips.
5. Render 1920×1080, 30fps master; check duration within 0.5 seconds of audio, non-silent audio at -17.5 to -14.5 LUFS, non-empty subtitles, transitions and end card.
6. Scan package and publish a new versioned release only for finished reviewed deliverables.
