# Image prompt bundle

Episode: Why You Want Success But Keep Choosing Comfort

## Instructions

Attach the canonical stickman reference to EVERY request. Generate one image per prompt. Each contact sheet is a single 3x3 landscape image, not nine separate files. Save sheet-01.png through sheet-18.png and thumbnail.png. Numbering below is prompt guidance only: no numbers printed in artwork. Upload originals at maximum available resolution, not chat screenshots. If 3840x2160 is unsupported, use the largest native 16:9 output; do not claim it is native 4K.

The 18-sheet / 162-panel budget is provisional: 1,975 script words at 140 words/minute gives about 14.1 minutes. Actual processed narration may require a different count using ceil(duration_seconds / 60 * 1.25). These prompts are the complete initial bundle, not a guarantee of the final count.

Only artwork is generated: all labels, diagrams, counters and captions are added during motion production. Odd/even composition supports paired reversals within each semantic sequence. Rest is not portrayed as a moral failure. Reuse the supplied canonical subscribe end card; do not generate a replacement.
